# Electron 桌面宠物

已完成：

- 第一阶段：透明背景、无边框、始终置顶、可拖拽的 Electron 桌面宠物窗口。
- 第二阶段：点击宠物切换临时动作，并显示本地文案对话气泡。
- 第三阶段：加入宠物状态系统，由独立状态机管理 `idle`、`happy`、`thinking`、`sleepy`。
- 第四阶段：加入 `normal` / `game` 模式系统，通过右键菜单切换模式。
- 第五阶段：加入右键菜单和信息模块注册表。
- 第六阶段：小游戏基础版，进入 game 模式后显示上下浮动的热气球。
- 第七阶段：小游戏加入弓箭、目标物和基础碰撞检测。
- 第八阶段：优化命中反馈、占位音效和宠物跟随气泡。
- 资源动作映射系统：普通模式和小游戏模式的宠物动作、箭、目标、命中特效都通过 `src/assetMap.js` 统一获取。
- 第九阶段：加入设置面板，可编辑额外文案、语言风格、气泡显示时间、长按触发时间、宠物整体尺寸、模块开关和闲置睡眠时间，并保存到本地 JSON。
- 第十阶段天气子模块：接入 Open-Meteo 天气接口，设置面板可编辑城市和点击天气提醒间隔。间隔到达后的第一次普通点击显示实时天气，紧接着第二次点击显示适合做什么。
- 第十阶段 Codex 子模块：接入本地 Codex 状态提醒。桌宠会读取本机 Codex 线程状态和可选状态文件；需要确认和执行完成只接受状态文件明确写入，避免误读 Codex 内部日志；需要确认和执行完成会弹出必须点击才消失的跟随气泡；额度提醒和额度重置提示使用普通自动消失气泡。
- 第十阶段即梦子模块：设置面板可配置即梦监控页面地址、检查间隔和完成通知。桌宠会定时读取即梦网页生成状态，显示生成中进度；检测到完成后会弹出跟随宠物的成功气泡，并发送系统通知。
- macOS 日历提醒模块：设置面板可开启日历提醒、调整检查间隔/提前提醒时间/未来查看范围，并可发送系统通知。桌宠会读取 macOS 日历中带备注的事件，事件接近时弹出跟随宠物的气泡；读不到日历权限时显示友好提示。
- 小游戏独立化：桌宠只保留通用 `game` 窗口模式，具体玩法通过游戏注册表启动；当前热气球射箭玩法已拆到 `src/games/balloon-shooter`，后续可以继续注册新的互动游戏。

## 运行

当前项目使用 JavaScript 和 Electron。

```bash
npm install
npm start
```

如果当前终端提示 `npm: command not found`，需要先安装 Node.js 的标准发行版，或让当前环境可访问 npm。安装完成后再运行上面的命令。

当前项目也包含一个本地启动脚本，可以直接运行：

```bash
./start.command
```

首次运行 `start.command` 时，如果还没有 `node_modules`，脚本会先执行 `npm install` 再启动应用。这个脚本需要系统已经安装 Node.js 和 npm。

## 新增小游戏

当前小游戏通过 `src/renderer/game/GameRegistry.js` 注册，由 `src/renderer/game/GameController.js` 统一进出。新增游戏时建议在 `src/games/<game-id>` 下建立独立目录，导出包含 `id`、`label`、`enter()`、`exit()` 的游戏对象，然后在 `src/renderer/renderer.js` 里注册。桌宠窗口仍然使用通用 `game` 模式扩展到屏幕范围，具体玩法不要直接写进 `ModeController`。

3. 保持桌宠运行，确认桌宠能显示最近 Codex 任务或运行中状态，但不会把 Codex 中间回复误报为完成。
4. 如需手动模拟状态，可以创建 `~/.codex/desktop-pet-codex-status.json`，写入：

```json
{
  "state": "waiting_confirmation",
  "message": "Codex 需要你确认一下。",
  "eventId": "test-confirm-1",
  "remainingPercent": 42,
  "quotaResetAt": "2026-06-03T18:00:00.000Z"
}
```

5. 把状态文件里的 `state` 改成 `completed` 并更新 `eventId`，确认完成气泡同样需要点击才消失。
6. 把 `state` 改成 `limited` 并更新 `eventId`；如果没有写 `quotaResetAt`，桌宠会按 5 小时后额度重置来安排提示。

## 当前阶段范围

当前实现到第十阶段天气、Codex、即梦与 macOS 日历提醒子模块。宠物、小游戏角色动作、箭、目标物和命中特效都通过 `src/assetMap.js` 统一获取资源；图片不存在时自动使用内置 SVG 占位图。进入 game 模式后，游戏层会扩展到屏幕范围，目标物生成在屏幕最左侧附近，宠物可在右侧拖动；鼠标在宠物以外的屏幕区域时会穿透游戏层，仍可操作桌面其他窗口。点击宠物会发射受重力影响的弓箭，长按蓄力后弓箭会更快、更直；命中后播放反馈、随机显示跟随宠物的气泡文案，并生成新的目标物。不显示分数和 combo 系统。右键菜单已合并为设置入口、热气球射箭和退出；设置面板可编辑额外文案、语言风格、气泡显示时间、长按触发时间、宠物整体尺寸、模块开关、闲置睡眠时间、天气城市、点击天气提醒间隔、Codex 状态文件、Codex 检查间隔、Codex 额度提醒、即梦页面地址、即梦检查间隔、完成通知和日历提醒参数，并保存到本地 JSON。天气通过 Open-Meteo 免 key 接口读取，失败时显示友好兜底文案。Codex 会读取本机 Codex 线程状态和可选状态文件；需要确认和完成只接受状态文件明确写入，并使用点击才消失的气泡，额度提醒和重置提示使用普通气泡。即梦通过独立 Electron 页面读取网页文字状态，如果页面需要登录，可从设置里打开即梦页面完成登录；生成完成时会显示气泡并发送系统通知。日历提醒会读取 macOS 日历中带备注的事件，接近开始时间时显示气泡和可选系统通知。小游戏已独立为可注册结构，当前热气球射箭游戏位于 `src/games/balloon-shooter`。

小游戏玩法参考 FC《猪小弟 / Pooyan》的右侧吊篮射左侧气球目标形式。
